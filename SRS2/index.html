Моделирование процесса приготовления лакокрасочных материалов (ЛКМ)

Цель работы

Разработка и исследование математической модели процесса смешивания компонентов лакокрасочных материалов в смесительном оборудовании для оптимизации технологических параметров.

Задачи работы

  • Изучить физико-химические основы процесса смешивания ЛКМ
  • Разработать дифференциальную математическую модель изменения концентрации
  • Провести вычислительные эксперименты при различных режимах смешивания
  • Выполнить оптимизацию технологических параметров по критерию энергозатрат
  • Проанализировать полученные результаты и сформулировать выводы

Описание технологического процесса

Процесс приготовления лакокрасочных материалов осуществляется в смесителе объёмом V путём смешивания двух основных компонентов:

Компонент G1

Смола (основной компонент ЛКМ)

Компонент G2

Растворитель (разбавитель)

Смешивание происходит при вращении мешалки со скоростью n (об/мин). В процессе смешивания происходит выравнивание концентрации компонентов по объёму смесителя, что характеризуется изменением концентрации C(t) во времени.

Теоретическая часть

Принцип работы смесителя

Смеситель представляет собой ёмкость с механической мешалкой, обеспечивающей интенсивное перемешивание компонентов. Основные технологические параметры:

  • V — объём смесителя (л)
  • n — скорость вращения мешалки (об/мин)
  • t — время смешивания (мин)
  • C(t) — концентрация компонента в момент времени t

Закон сохранения материи в динамике

Для динамической системы справедливо уравнение материального баланса:

Приход = Убыль + Приращение

В дифференциальной форме для смесителя:

(1.15) d(V·C)/dt = G₁·C₁ - G₂·C₂

Где:

  • G₁ — расход компонента G1 (кг/ч)
  • G₂ — расход компонента G2 (кг/ч)
  • C₁, C₂ — концентрации на входе

Дифференциальная модель

При постоянном объёме смесителя (V = const) и assuming G₁ = G₂ = G:

(1.16) V·dC/dt = G·(C₁ - C)

После преобразования получаем дифференциальное уравнение первого порядка, описывающее изменение концентрации во времени.

Уравнение изменения концентрации

С использованием преобразований Лагранжа решение дифференциального уравнения:

(1.17) C(t) = C₀·e^(-k·t) + C∞·(1 - e^(-k·t))

Где C∞ — равновесная концентрация (целевое значение).

Коэффициент интенсивности k зависит от скорости вращения мешалки:

k = A₁·n + A₂

Метод наименьших квадратов (МНК)

Для определения коэффициентов A₁ и A₂ используется МНК. Система нормальных уравнений:

(1.21) Σ(nᵢ·kᵢ)·A₁ + Σ(kᵢ)·A₂ = Σ(nᵢ·kᵢ²)
(1.22) Σ(nᵢ²)·A₁ + Σ(nᵢ)·A₂ = Σ(nᵢ·kᵢ)

Решение системы:

(1.23) A₁ = (Σ(nᵢ·kᵢ²)·Σ(nᵢ) - Σ(kᵢ)·Σ(nᵢ·kᵢ)) / D
(1.24) A₂ = (Σ(nᵢ²)·Σ(nᵢ·kᵢ) - Σ(nᵢ·kᵢ²)·Σ(nᵢ)) / D

Где D = Σ(nᵢ²)·Σ(nᵢ) - (Σ(nᵢ))² — определитель системы.

Ограничения модели

  • V > 0 (объём должен быть положительным)
  • 100 ≤ n ≤ 500 (скорость мешалки, об/мин)
  • 1 ≤ t ≤ 20 (время смешивания, мин)
  • 0 ≤ C(t) ≤ 100 (концентрация в процентах)
  • k > 0 (коэффициент интенсивности положительный)
